# Contributing

Contributions are welcome — bug reports, feature suggestions, and pull requests.

## Development Setup

1. Fork and clone the repository
2. Follow the setup steps in README.md
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Open a pull request with a clear description of what and why

## Code Style

- TypeScript strict mode where possible
- NestJS conventions for backend (services, controllers, modules)
- Functional React components with hooks, no class components
- Tailwind utility classes for styling

## Reporting Issues

Please include:
- Node.js version (`node -v`)
- OS and version
- Steps to reproduce
- Expected vs actual behavior
